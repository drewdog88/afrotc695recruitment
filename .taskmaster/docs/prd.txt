# AFROTC 695 Recruitment Management System - Product Requirements Document

## Project Overview
A comprehensive Flask-based recruitment management system for AFROTC Detachment 695 at the University of Portland. The system streamlines and secures the recruitment process for Air Force ROTC, providing robust tools for tracking potential recruits, managing existing cadets, coordinating with high school contacts, scheduling recruitment events, and maintaining detailed activity logs.

## Current Status
The application is fully developed and functional locally with the following features:
- Complete user management system with role-based access
- Comprehensive data management for recruits, cadets, and contacts
- Event calendar and scheduling system
- Advanced analytics and reporting dashboard
- Security features including password policies and activity logging
- Backup and restore functionality
- Document management system
- Export capabilities in multiple formats
